# Ride Ledger

Personal ride ledger — Komoot (cycling) + Garmin (running/swimming) dashboard.

- Live site: https://santogioia.github.io/ride-ledger/
- Source: `personal/Workspace/bike-tour-dashboard.html` in Ciaobot vault
- Daily auto-update via Ciaobot schedule at 06:00 Europe/Zurich (`personal/Workspace/update-dashboard.py`)

Data is baked into the HTML; planned tours persist via browser localStorage.
